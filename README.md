# حسابداری برنج آریا — ربات تلگرام

## امکانات
- ثبت خرید
- ثبت فروش نقدی و نسیه
- ثبت پرداخت مشتری
- ثبت هزینه‌های مغازه
- موجودی کالا بر اساس خرید و فروش
- حساب مشتریان
- گزارش کلی
- جستجوی تراکنش‌ها
- تاریخ شمسی و ساعت خودکار
- ذخیره اطلاعات در SQLite

## راه‌اندازی

### 1) ساخت ربات
در تلگرام به `@BotFather` بروید و `/newbot` را بزنید.
نام ربات و username را انتخاب کنید و Token را بگیرید.

### 2) نصب
Python 3.10 یا بالاتر نصب باشد:

```bash
pip install -r requirements.txt
```

### 3) تنظیم Token

Linux/macOS:
```bash
export TELEGRAM_BOT_TOKEN="TOKEN"
python bot.py
```

Windows PowerShell:
```powershell
$env:TELEGRAM_BOT_TOKEN="TOKEN"
python bot.py
```

یا مقدار TOKEN را مستقیم در `bot.py` جایگزین کنید.

## نکته امنیتی
Token ربات را برای هیچ‌کس ارسال نکنید. اگر Token لو رفت، از BotFather آن را revoke کنید.

## دیتابیس
فایل `aria_accounting.db` به صورت خودکار ساخته می‌شود. از این فایل مرتباً نسخه پشتیبان بگیرید.

## نسخه بعدی پیشنهادی
برای استفاده واقعی مغازه بهتر است این موارد نیز اضافه شوند:
- قفل کردن ربات برای Telegram ID صاحب مغازه
- گزارش روزانه/ماهانه دقیق
- سود تقریبی بر اساس قیمت خرید و فروش
- ثبت چند قلم کالا در یک فاکتور
- سررسید اقساط و یادآوری
- ویرایش/حذف تراکنش
- خروجی Excel
- پشتیبان‌گیری خودکار
- داشبورد مدیریتی
